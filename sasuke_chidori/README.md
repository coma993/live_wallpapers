# Sasuke — Chidori (Lively Wallpaper)

1. Otvori **Lively Wallpaper**.
2. Klikni **Add Wallpaper** / **+**.
3. Izaberi datoteku `index.html` iz ovog foldera.
4. Postavi je kao pozadinu.
5. U Lively podešavanjima uključi prosleđivanje miša / **Mouse input** za ovu pozadinu ako klikovi ne stižu do animacije.

Pritisni i drži klik na Sasukeu na desnoj strani ekrana. Dok držiš klik, pomeri miš prema smeru u kojem želiš da puca; kada pustiš klik, Chidori se ispaljuje u tom pravcu. Ikonice je najbolje držati na levoj strani, gde je slika tamnija i mirnija.
